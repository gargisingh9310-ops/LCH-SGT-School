# LCH SGT High School Website (Homepage)

> **40 Years of Excellence in Education**  
> Supported by the **Lions Club of Hyderabad**  
> *"Where Learning Goes Beyond the Classroom"*

This repository contains the first-phase presentation website for **LCH SGT High School**, establishing a premium, modern visual identity, layout, typography, motion system, and interactive educational components.

---

## 🏛️ Project Highlights

- **Visual Identity**: Official school logo (tree canopy, book, silhouette) and Lions Club of Hyderabad heritage badge preserved without alteration.
- **Color Direction**: Curated palette of Deep Emerald (`#064E3B`), Forest Green (`#047857`), Warm Amber (`#D97706`), Soft Gold (`#F59E0B`), and Warm Ivory (`#FAF8F0`).
- **Interactive React Bits Components**:
  - `ParticleText`: Interactive constellation canvas text effect reacting to cursor motion.
  - `ProfileCard`: 3D perspective tilt with holographic glare effect for the Principal's message.
  - `CountUp`: Dynamic counter for the verified **40+** Years of Educational Excellence milestone.
  - `FlexCarousel`: Interactive expanding card accordion showcasing campus activities and student development.
- **10 Campus Facilities**: Editorial responsive card grid featuring School Building, Class Rooms, Science Labs, Library, Playground, Music & Dance, Transport, Art Room, Indoor Sports, and Computer Lab.
- **CSR Partnership Section**: Dedicated corporate social responsibility engagement area with proposal modal.
- **Smooth Motion**: Lenis smooth scrolling synchronized with GSAP ScrollTrigger ticker.

---

## 🛠️ Technology Stack

- **Framework**: [React 18](https://react.dev/) + [Vite](https://vitejs.dev/)
- **Routing**: [React Router DOM](https://reactrouter.com/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Motion & Scrolling**: [GSAP](https://greensock.com/gsap/) with [ScrollTrigger](https://greensock.com/scrolltrigger/) & [Lenis](https://lenis.darkroom.engineering/)
- **Icons**: [Lucide React](https://lucide.dev/)

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Locally in Development
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 3. Build for Production
```bash
npm run build
```
